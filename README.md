# 🍎 Fruit Catcher - Arcade Challenge

## 📌 Project Description
Fruit Catcher is a 2D arcade game in which players control a basket to catch falling fruits, earn points, and avoid bombs. The game includes a timer, lives system, background music, sound effects, and increasing difficulty.

## 🎮 Game Features
- Start screen with game instructions.
- Basket movement using left and right arrow keys.
- Falling fruits and bombs.
- Normal fruit gives 10 points.
- Golden Star gives 30 bonus points.
- Bomb collision reduces one life.
- 60-second countdown timer.
- Increasing game difficulty.
- Pause and Resume functionality.
- Background music during gameplay.
- Background music pauses and resumes with the game.
- Sound effects for collecting fruits and hitting bombs.
- Game Over screen with final score.
- Play Again option to restart the game.
- Custom cartoon garden background.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🕹️ How to Play
1. Click the START GAME button.
2. Use the left and right arrow keys to move the basket.
3. Catch normal fruits to earn 10 points.
4. Catch Golden Stars to earn 30 points.
5. Avoid bombs to save your lives.
6. Use the PAUSE button to pause or resume the game.
7. Try to achieve the highest score before time runs out.
